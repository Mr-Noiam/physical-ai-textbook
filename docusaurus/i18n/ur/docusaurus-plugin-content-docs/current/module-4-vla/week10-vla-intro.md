# ہفتہ 10: Vision-Language-Action کا ملاپ

## تعارف

**Vision-Language-Action (VLA)** ماڈلز کمپیوٹر وژن، قدرتی زبان کی پروسیسنگ، اور روبوٹ کنٹرول کے ملاپ کی نمائندگی کرتے ہیں۔ اس ہفتے، آپ سیکھیں گے کہ کس طرح CLIP، LLaVA، اور RT-2 جیسے ماڈلز ہیومینائیڈز کو بصری مناظر سمجھنے، احکامات کی تشریح کرنے، اور کاموں کو انجام دینے کے قابل بناتے ہیں۔

## VLA نمونہ

**اجزاء**:
- **Vision Encoder**: CLIP, DINOv2, MAE
- **Language Model**: GPT-4, LLaMA, PaLM
- **Action Decoder**: Diffusion policies, transformers
- **Embodied Reasoning**: Chain-of-thought, planning

## Zero-Shot Object Recognition کے لیے CLIP

**CLIP** (Contrastive Language-Image Pre-training) تصاویر اور متن کو ایک مشترکہ embedding space میں نقشہ بناتا ہے۔

## خلاصہ

اس ہفتے آپ نے سیکھا:

- VLA نمونہ: Vision + Language + Action
- Zero-shot object detection کے لیے CLIP
- Visual question answering کے لیے LLaVA
- RT-2 فن تعمیر کے تصورات
- ROS 2 کے ساتھ VLMs کو مربوط کرنا
- مکمل object fetching pipeline
