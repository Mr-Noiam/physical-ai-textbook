# ہفتہ 11: Whisper کے ساتھ Voice-to-Action

## تعارف

اس ہفتے، آپ **Whisper** (speech recognition)، **LLMs** (reasoning)، اور action primitives استعمال کرتے ہوئے اپنے ہیومینائیڈ کے لیے ایک مکمل voice control نظام بنائیں گے۔ pipeline حقیقی وقت میں بولی گئی کمانڈز کو روبوٹ کے افعال میں تبدیل کرتا ہے۔

## خلاصہ

اس ہفتے آپ نے سیکھا:

- Speech-to-text کے لیے Whisper
- حقیقی وقت میں مائیکروفون ان پٹ
- LLM command parsing
- Voice-to-action pipeline
