# ہفتہ 1: جسمانی AI کی بنیادیں
## جسمانی ذہانت کا تعارف
خوش آمدید ہفتہ 1! اس ہفتے، ہم **Physical AI** کے بنیادی تصورات کا جائزہ لیں گے—مصنوعی ذہانت کے نظام جو جسمانی پلیٹ فارم جیسے روبوٹ کے ذریعے جسمانی دنیا کے ساتھ تعامل کرتے ہیں اور اس سے سیکھتے ہیں۔
### جسمانی AI کیا ہے؟
**فزیکل AI** سے مراد وہ AI نظام ہیں جو:1. **حساسات** (کیمرے، LiDAR، IMUs) کے ذریعے جسمانی دنیا کا ادراک کریں۔2. **مکانی تعلقات، طبیعیات، اور سببیت** کے بارے میں **سوچیں**3. **عمل** کریں حقیقی دنیا میں ایکچوئیٹرز (موٹرز، گرپرز) کے ذریعے4. **جسمانی تعاملات اور فیڈبیک** سے سیکھیں
محض ڈیجیٹل AI (جیسے ChatGPT) کے برعکس، جسمانی AI کو درج ذیل کا سامنا کرنا پڑتا ہے:- **حقیقی وقت کی پابندیاں**: فیصلے ملی سیکنڈز میں کیے جانے چاہئیں- **عدم یقین**: سینسر شور مچاتے ہیں، دنیا غیر متوقع ہے- **حفاظت**: غلطیاں جسمانی نقصان کا باعث بن سکتی ہیں- **جسم**: AI کا "جسم" (روبوٹ کی شکل و صورت) اس بات پر اثر انداز ہوتا ہے کہ یہ کیا کر سکتا ہے۔
### انسان نما روبوٹ کیوں؟
ہیومینائیڈ روبوٹ منفرد فوائد پیش کرتے ہیں:
**1. انسان کے ڈیزائن کردہ ماحول**- ہماری دنیا انسانوں کے لیے بنائی گئی ہے (سیڑھیاں، دروازے، فرنیچر)- ہیومینائیڈ شکل کا عنصر ان جگہوں پر قدرتی طور پر نیویگیٹ کر سکتا ہے۔
**2. بصری تعامل**- لوگ انسانی شکل کے جسمانی زبان اور اشاروں کو سمجھتے ہیں۔- رویے کی پیش گوئی اور تعاون کرنا آسان تر ہے
**3. ہمہ گیری**- دوپائی چلنے کی صلاحیت پیچیدہ نیویگیشن کو ممکن بناتی ہے- بازوؤں اور ہاتھوں کے ساتھ ماہرانہ چالاکی- کثیر طریقہ تعامل (نظر، تقریر، چھونا)
**۴. تحقیقاتی پلیٹ فارم**- انسانی ادراک اور حرکتی کنٹرول کے نظریات کا امتحان کریں- جسمانی AI صلاحیتوں کے لیے بینچ مارک

خود مختار انسانی شکل کے روبوٹ کی تعمیر کے لیے متعدد پرتوں کو یکجا کرنا ضروری ہے:

### تہہ کی تفصیل
**ہارڈویئر کی تہ**:- **ایکچوایٹرز**: موٹرز (سرو، برش لیس، اسٹیپر)- **سینسرز**: کیمرہ، LiDAR، IMU، فورس/ٹارک سینسرز- **کمپیوٹ**: سنگل بورڈ کمپیوٹرز (Jetson)، GPUs
**مڈل ویئر (ROS 2)**:- تقسیم شدہ روبوٹ سسٹمز کے لیے مواصلاتی بنیادی ڈھانچہ- معیاری پیغام کے فارمیٹس- ڈیبگنگ، بصری سازی، اور سیمولیشن کے لیے ٹولز
**سیمولیشن**:- ہارڈویئر پر تعینات کرنے سے پہلے الگورڈمز کو محفوظ طریقے سے جانچیں- مصنوعی تربیتی ڈیٹا تیار کریں- تیز رفتار پروٹو ٹائپنگ
**ادراک**:- مقامی سازی اور نقشہ سازی کے لیے بصری SLAM- اشیاء کی شناخت اور تقسیم- گہرائی کا تخمینہ اور 3D تعمیر نو
**منصوبہ بندی اور نیویگیشن**:- راستے کی منصوبہ بندی (A*, RRT)- رکاوٹ سے بچاؤ- ہیرا پھیری کے لیے حرکت کی منصوبہ بندی
**اعلیٰ سطح کی AI**:- بصری-زبان ماڈلز (CLIP, LLaVA)- استدلال کے لیے بڑے زبان ماڈل- پالیسیوں کے لیے تقویت سیکھنا
## جسمانی AI میں اہم چیلنجز
### 1. سمولیشن سے حقیقی دنیا کا فرق
**مسئلہ**: سمیولیشن میں تربیت یافتہ روبوٹ اکثر حقیقی دنیا میں ناکام ہوجاتے ہیں۔
**کیوں؟**- سمیولیٹرز طبیعیات (رگڑ، مطابقت) کا مکمل ماڈل نہیں بناتے۔- بصری ظاہری شکل مختلف ہوتی ہے (روشنی، ساختیں)- سینسر کی شور کو درست طور پر ماڈل نہیں کیا گیا
**حل**:- **ڈومین رینڈمائزیشن**: تربیت کے دوران سمولیشن کے پیرامیٹرز میں تبدیلی کریں- **سسٹم کی شناخت**: حقیقی دنیا کے طبیعیات کے پیرامیٹرز کی پیمائش کریں- **سیم-ٹو-ریئل ٹرانسفر لرننگ**: حقیقی دنیا میں فائن ٹیون کریں
### 2. حقیقی وقت کی کارکردگی
**مسئلہ**: AI ماڈلز (خاص طور پر ڈیپ لرننگ) سست ہو سکتے ہیں۔
**ضروریات**:- **ادراک**: بصری پروسیسنگ کے لیے 30+ FPS- **کنٹرول**: 100+ ہرٹز مستحکم موٹر کنٹرول کے لیے- **منصوبہ بندی**: &lt;100ms کے لئے ردعمل کے رویے
**حل**:- **ہارڈویئر کی تیز رفتاری**: GPUs، TPUs، خصوصی چپس- **ماڈل کی اصلاح**: مقدار بندی، چھانٹنا، عرق کشی- **درجہ بندی کنٹرول**: تیز کم سطح کے لوپس، سست اعلیٰ سطح کی منصوبہ بندی
### ۳. حفاظت اور مضبوطی
**مسئلہ**: جسمانی نظام اگر خراب ہو جائیں تو نقصان پہنچا سکتے ہیں۔
**ضروریات**:- **خرابی کا پتہ لگانا**: سینسر کی صحت کی نگرانی کریں اور بے قاعدگیاں دریافت کریں- **خوش اسلوبی سے تنزلی**: محفوظ متبادل رویے- **ایمرجنسی اسٹاپ**: ہارڈ ویئر کل سوئچ
**حل**:- **اضافی**: اہم افعال کے لیے متعدد سینسر- **باضابطہ تصدیق**: حفاظتی خصوصیات کو ریاضیاتی طور پر ثابت کریں- **انسانی نگرانی**: ٹیلی آپریشن بیک اپ
### ۴. ڈیٹا کی مؤثریت
**مسئلہ**: حقیقی دنیا کے روبوٹ کے ڈیٹا کو جمع کرنا مہنگا اور وقت طلب ہے۔
**چیلنجز**:- ڈیپ لرننگ کے لیے لاکھوں مثالوں کی ضرورت ہوتی ہے- ہر روبوٹ کی تعامل میں سیکنڈز سے منٹ لگتے ہیں- ہارڈ ویئر کی خرابی اور حفاظتی خدشات
**حل**:- **سیمولیشن**: مصنوعی ڈیٹا پر پہلے سے تربیت کریں- **منتقلی سیکھنا**: پہلے سے تربیت یافتہ ماڈلز کا فائدہ اٹھائیں (ImageNet, CLIP)- **Few-shot learning**: محدود مظاہر سے سیکھنا- **خود نگرانی سیکھنا**: بغیر لیبل کے تعامل کے ڈیٹا سے سیکھیں
## ROS 2 کا کردار
**ROS 2** (روبوٹ آپریٹنگ سسٹم 2) روبوٹکس کے لیے ایک معیاری مڈل ویئر ہے۔ اسے روبوٹ سافٹ ویئر کے لیے "آپریٹنگ سسٹم" کے طور پر سمجھیں۔
### ROS 2 کیوں؟
**1. ماڈیولرٹی**- پیچیدہ نظاموں کو دوبارہ استعمال کے قابل اجزاء (نوڈز) میں تقسیم کریں۔- ہر نوڈ ایک چیز کو اچھی طرح انجام دیتا ہے (کیمرہ ڈرائیور، منصوبہ ساز، کنٹرولر)
**2. زبان سے آزاد**- Python، C++، یا دیگر زبانوں میں نوڈز لکھیں- نوڈز معیاری پیغامات کے ذریعے بات چیت کرتے ہیں۔
**3. تقسیم شدہ کمپیوٹنگ**- نوڈز مختلف کمپیوٹروں پر چل سکتے ہیں- سنگل بورڈ کمپیوٹرز سے GPU کلسٹرز تک اسکیل کریں
**۴. ماحولیاتی نظام**- ہزاروں اوپن سورس پیکجز- عام ہارڈویئر کے لیے ڈرائیورز- SLAM، نیویگیشن، اور ہیرا پھیری کے لیے الگورڈمز
**5. صنعت کی اپنائیت**- بوسٹن ڈائنامکس، ناسا، اور آٹوموٹو کمپنیوں کے ذریعہ استعمال کیا جاتا ہے۔- فعال کمیونٹی اور تجارتی حمایت
### ROS 2 بمقابلہ ROS 1
ROS 2، ROS 1 میں بہتری لاتا ہے:
| خصوصیت | ROS 1 | ROS 2 ||---------|-------|-------|| **حقیقی وقت** | نہیں | جی ہاں (DDS کے ساتھ) || **سیکیورٹی** | کم سے کم | بلٹ ان انکرپشن || **کئی روبوٹ** | مشکل | مقامی حمایت || **ونڈوز/macOS** | محدود | مکمل حمایت || **زندگی کا دورانیہ** | نہیں | منظم نوڈ زندگی کا دورانیہ |
ہم **ROS 2 Humble** (LTS ریلیز، جو 2027 تک سپورٹ کی جائے گی) استعمال کریں گے۔
## انسانی شکل کے روبوٹ کی ساخت
آئیے ایک انسانی شکل والے روبوٹ کی عام ساخت کو سمجھتے ہیں:
### آزادی کے درجے (DOF)
انسان نما روبوٹ میں عام طور پر **20-40 DOF** ہوتے ہیں:
```
Head: 3 DOF (pan, tilt, roll)
├── Neck: 2 DOF
│
Torso: 3 DOF (pitch, yaw, roll)
│
Arms (×2): 7 DOF each = 14 DOF
├── Shoulder: 3 DOF (pitch, yaw, roll)
├── Elbow: 1 DOF (pitch)
├── Wrist: 3 DOF (pitch, yaw, roll)
│
Hands (×2): 4-12 DOF each (finger articulation)
│
Legs (×2): 6 DOF each = 12 DOF
├── Hip: 3 DOF (pitch, yaw, roll)
├── Knee: 1 DOF (pitch)
├── Ankle: 2 DOF (pitch, roll)
```

**کل**: ~30 DOF (ہاتھوں کو چھوڑ کر)
### سینسر سوئٹ
انسانی شکل کے روبوٹ میں عام سینسر:
**نظر**:
- RGB کیمرے (گہرائی کے لیے سٹیریو)
- گہرائی کے کیمرے (RealSense, ZED)
- 360° کیمرے برائے ہمہ جہتی نظر
**پروپریو سیپشن** (اپنی حالت کا احساس):
- جوائنٹ انکوڈرز (پوزیشن، رفتار)
- پاؤں اور جوڑوں میں فورس/ٹارک سینسرز
- IMU (انرشیل میجرمنٹ یونٹ) برائے سمت
**ایکسٹروسیپشن** (ماحول کا ادراک):
- 3D نقشہ سازی کے لیے LiDAR
- ٹکراؤ سے بچنے کے لیے قریبیت سینسر
- آڈیو ان پٹ کے لیے مائیکروفون
## مثال: NVIDIA Isaac Sim ہیومینائیڈ
آئیے NVIDIA Isaac Sim میں ایک حوالہ انسانی شکل کا ماڈل دیکھتے ہیں:
**خصوصیات**:
- **اونچائی**: 1.7m
- **وزن**: 60kg
- **DOF**: 28 (صرف جسم)
- **کمپیوٹ**: NVIDIA Jetson AGX Orin
- **کیمرے**: 2× اسٹیرئیو جوڑے (سامنے + پیچھے)
- **LiDAR**: 1× 360° LiDAR
- **عملیاتی**: برش لیس موٹرز کے ساتھ ہارمونک ڈرائیوز
**صلاحیتیں**:
- چلنے کی رفتار: 1.5 میٹر فی سیکنڈ
- کام کرنے کا وقت: 2 گھنٹے (بیٹری)
- بوجھ: 10 کلوگرام (بازو)
- توازن کی بحالی: 30° تک کی خلل
ہم اس کورس کے دوران اس روبوٹ کی نقل کریں گے!

## عملی جائزہ: ROS 2 کی تنصیب
جب کہ ہم اگلے ہفتے ROS 2 میں گہرائی میں جائیں گے، آئیے تنصیب کے ساتھ شروع کرتے ہیں۔
### ROS 2 Humble کی تنصیب (Ubuntu 22.04)
```bash
# Set up sources
sudo apt update && sudo apt install -y software-properties-common
sudo add-apt-repository universe
sudo apt update && sudo apt install curl -y

# Add ROS 2 GPG key
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

# Add repository
echo "deb [arch=$(dpkg --print-architecture) \
signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
| sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

# Install ROS 2 Humble Desktop
sudo apt update
sudo apt install -y ros-humble-desktop

# Install development tools
sudo apt install -y python3-colcon-common-extensions python3-rosdep

# Initialize rosdep
sudo rosdep init
rosdep update
```

### تنصیب کی تصدیق کریں
```bash
# Source ROS 2 environment
source /opt/ros/humble/setup.bash

# Test with demo nodes
ros2 run demo_nodes_cpp talker
```

آپ کو پیغامات شائع ہوتے ہوئے دیکھنے چاہئیں!
**نصیحت**: اپنے `~/.bashrc` میں `source /opt/ros/humble/setup.bash` شامل کریں تاکہ ROS 2 خود بخود لوڈ ہو جائے۔
