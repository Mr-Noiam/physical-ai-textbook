# مارک ڈاؤن خصوصیات

Docusaurus **[مارک ڈاؤن](https://daringfireball.net/projects/markdown/syntax)** اور کچھ **اضافی خصوصیات** کی حمایت کرتا ہے۔

## فرنٹ میٹر

مارک ڈاؤن دستاویزات کے اوپری حصے میں میٹا ڈیٹا ہوتا ہے جسے [فرنٹ میٹر](https://jekyllrb.com/docs/front-matter/) کہتے ہیں:

```text title="my-doc.md"
// highlight-start
---
id: my-doc-id
title: My document title
description: My document description
slug: /my-custom-url
---
// highlight-end

## مارک ڈاؤن ہیڈنگ

[لنکس](./hello.md) کے ساتھ مارک ڈاؤن متن
```

## لنکس

باقاعدہ مارک ڈاؤن لنکس کی حمایت کی جاتی ہے، یو آر ایل پاتھ یا متعلقہ فائل پاتھ کا استعمال کرتے ہوئے۔

```md
آئیے دیکھتے ہیں کہ [ایک صفحہ کیسے بنائیں](/create-a-page)۔
```

```md
آئیے دیکھتے ہیں کہ [ایک صفحہ کیسے بنائیں](./create-a-page.md)۔
```

**نتیجہ:** آئیے دیکھتے ہیں کہ [ایک صفحہ کیسے بنائیں](./create-a-page.md)۔

## تصاویر

باقاعدہ مارک ڈاؤن تصاویر کی حمایت کی جاتی ہے۔

آپ اسٹیٹک ڈائرکٹری (`static/img/docusaurus.png`) میں تصاویر کا حوالہ دینے کے لیے مطلق پاتھ استعمال کر سکتے ہیں:

```md
![Docusaurus logo](/img/docusaurus.png)
```

![Docusaurus logo](/img/docusaurus.png)

آپ موجودہ فائل کے متعلقہ تصاویر کا بھی حوالہ دے سکتے ہیں۔ یہ خاص طور پر ان تصاویر کو مارک ڈاؤن فائلوں کے قریب رکھنے کے لیے مفید ہے جو انہیں استعمال کرتی ہیں:

```md
![Docusaurus logo](./img/docusaurus.png)
```

## کوڈ بلاکس

مارک ڈاؤن کوڈ بلاکس کو سنٹیکس ہائی لائٹنگ کے ساتھ سپورٹ کیا جاتا ہے۔

````md
```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>ہیلو، Docusaurus!</h1>;
}
```
````

## ایڈمونیشنز

Docusaurus کے پاس ایڈمونیشنز اور کال آؤٹ بنانے کے لیے ایک خاص سنٹیکس ہے:

```md
:::tip میری ٹپ

اس زبردست فیچر آپشن کا استعمال کریں

:::

:::danger خیال رکھیں

یہ عمل خطرناک ہے

:::
```

## MDX اور ری ایکٹ اجزاء

[MDX](https://mdxjs.com/) آپ کی دستاویزات کو زیادہ **انٹرایکٹو** بنا سکتا ہے اور مارک ڈاؤن کے اندر کسی بھی **ری ایکٹ اجزاء** کو استعمال کرنے کی اجازت دیتا ہے:

```jsx
export const Highlight = ({children, color}) => (
  <span
    style={{
      backgroundColor: color,
      borderRadius: '20px',
      color: '#fff',
      padding: '10px',
      cursor: 'pointer',
    }}
    onClick={() => {
      alert(`You clicked the color ${color} with label ${children}`)
    }}>
    {children}
  </span>
);

یہ <Highlight color="#25c2a0">Docusaurus سبز</Highlight> ہے!

یہ <Highlight color="#1877F2">Facebook نیلا</Highlight> ہے!
```
