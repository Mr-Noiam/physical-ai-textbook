# بلاگ پوسٹ بنائیں

Docusaurus ہر بلاگ پوسٹ کے لیے **ایک صفحہ** بناتا ہے، بلکہ **بلاگ انڈیکس صفحہ**، **ٹیگ سسٹم**، اور **RSS** فیڈ بھی...

## اپنی پہلی پوسٹ بنائیں

`blog/2021-02-28-greetings.md` پر ایک فائل بنائیں:

```md title="blog/2021-02-28-greetings.md"
---
slug: greetings
title: سلام!
authors:
  - name: Joel Marcey
    title: Docusaurus 1 کا شریک تخلیق کار
    url: https://github.com/JoelMarcey
    image_url: https://github.com/JoelMarcey.png
  - name: Sébastien Lorber
    title: Docusaurus کا منتظم
    url: https://sebastienlorber.com
    image_url: https://github.com/slorber.png
tags: [greetings]
---

مبارک ہو، آپ نے اپنی پہلی پوسٹ بنا لی ہے!

جتنا چاہیں اس پوسٹ کے ساتھ تجربہ کریں اور اسے ایڈٹ کریں۔
```

اب ایک نئی بلاگ پوسٹ [http://localhost:3000/blog/greetings](http://localhost:3000/blog/greetings) پر دستیاب ہے۔
