# مبارک ہو!

آپ نے **Docusaurus کی بنیادیات** سیکھ لی ہیں اور **ابتدائی ٹیمپلیٹ** میں کچھ تبدیلیاں کی ہیں۔

Docusaurus میں **بہت کچھ ہے**!

کیا آپ کے پاس **5 مزید منٹ** ہیں؟ **[ورژننگ](../tutorial-extras/manage-docs-versions.md)** اور **[i18n](../tutorial-extras/translate-your-site.md)** پر ایک نظر ڈالیں۔

کیا اس ٹیوٹوریل میں کچھ **غیر واضح** یا **بگ** ہے؟ [براہ کرم اسے رپورٹ کریں!](https://github.com/facebook/docusaurus/discussions/4610)

## آگے کیا ہے؟

- [سرکاری دستاویزات](https://docusaurus.io/) پڑھیں
- اپنی سائٹ کی ترتیب کو [`docusaurus.config.js`](https://docusaurus.io/docs/api/docusaurus-config) کے ساتھ تبدیل کریں
- [`themeConfig`](https://docusaurus.io/docs/api/themes/configuration) کے ساتھ نیویگیشن بار اور فوٹر آئٹمز شامل کریں
- ایک حسب ضرورت [ڈیزائن اور لے آؤٹ](https://docusaurus.io/docs/styling-layout) شامل کریں
- ایک [تلاش بار](https://docusaurus.io/docs/search) شامل کریں
- [Docusaurus شوکیس](https://docusaurus.io/showcase) میں تحریکیں تلاش کریں
- [Docusaurus کمیونٹی](https://docusaurus.io/community/support) میں شامل ہوں
