# اپنی سائٹ کو ڈپلائی کریں

Docusaurus ایک **اسٹیٹک سائٹ جنریٹر** ہے (جسے **[Jamstack](https://jamstack.org/)** بھی کہا جاتا ہے)۔

یہ آپ کی سائٹ کو سادہ **اسٹیٹک HTML، JavaScript اور CSS فائلوں** کے طور پر بناتا ہے۔

## اپنی سائٹ بنائیں

اپنی سائٹ **پروڈکشن** کے لیے بنائیں:

```bash
npm run build
```

اسٹیٹک فائلیں `build` فولڈر میں تیار کی جاتی ہیں۔

## اپنی سائٹ کو ڈپلائی کریں

اپنی پروڈکشن بلڈ کو مقامی طور پر ٹیسٹ کریں:

```bash
npm run serve
```

اب `build` فولڈر [http://localhost:3000/](http://localhost:3000/) پر فراہم کیا جا رہا ہے۔

آپ اب `build` فولڈر کو **تقریباً کہیں بھی** آسانی سے، **مفت** یا بہت کم قیمت پر ڈپلائی کر سکتے ہیں (**[ڈپلائمنٹ گائیڈ](https://docusaurus.io/docs/deployment)** پڑھیں)۔
