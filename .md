  1. You push: The entire root folder to GitHub
  2. GitHub Actions sees: .github/workflows/deploy-docusaurus.yml
  3. Workflow builds: Only the docusaurus/ folder
  4. GitHub Pages hosts: Only the built frontend

  Result: Backend code stays in the repo, but GitHub Pages only serves the frontend!

  4. Runs: npm run build
  5. Deploys ONLY the docusaurus/build/ folder to gh-pages branch
